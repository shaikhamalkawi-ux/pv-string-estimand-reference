# Data-access and reproducibility boundaries

**Public contents**: Standard-library Python implementation of screening/aggregation for artificial PV-string measurements and a generated synthetic fixture.

**Not included**: Raw field data, calibrated sensor streams, physical product/manufacturer descriptions, mappings of coded strings to actual devices or inverters, event logs, original site-specific source files, site-specific derived values, proprietary rated-power crosswalks, calibration audit records, non-public supplementary analyses, or any institutionally restricted archive.

**Permitted claim when citing this repository**: The public code demonstrates the declared screening and aggregation mechanics on synthetic data.

**Not permitted**: Claims that public readers can recompute a particular confidential site's medians, temporal bootstrap intervals, simultaneous confidence family, or field ranking without access to controlled source data.

Contact the authors and data owner for any data-access inquiry; access is subject to their review and is not guaranteed. Do not file GitHub issues attaching protected content.
